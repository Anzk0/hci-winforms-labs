# HCI Windows Forms labs

The C# lab sheets from the Human Computer Interaction module, Year 1 at Salford (September to October 2025). They were my first time using Visual Studio and Windows Forms.

| Folder | Lab | What it covers |
|---|---|---|
| `lab-2-3-first-form` | 2 and 3 | Making a project, the designer, a first form |
| `lab-4-multiple-forms` | 4 | Opening a second form and passing data to it |
| `lab-5-calculator` | 5 | Moving logic out of the form into its own `Calculator` class |

## Running them

Open the `.sln` file in any folder with Visual Studio (Windows, .NET Framework) and press F5.

See [PROCESS.md](PROCESS.md) for notes on each lab.
